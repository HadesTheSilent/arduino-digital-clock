# Component List

## Required Components

| Component | Quantity | Specifications |
|-----------|----------|----------------|
| Arduino Uno R3 | 1 | ATmega328P microcontroller |
| 16x2 LCD Display | 1 | HD44780 compatible, 5V |
| Push Buttons | 3 | Momentary, normally open |
| Potentiometer | 1 | 10kΩ linear taper |
| Resistors | 3 | 10kΩ, 1/4W |
| Resistor | 1 | 220Ω, 1/4W |
| Breadboard | 1 | Half-size (400 tie points) |
| Jumper Wires | 1 pack | Male-to-male, various colors |

## Notes
- This project was originally designed and tested in Tinkercad simulator
- Generic Arduino clones work fine and cost less
- LCD displays are available in different colors (blue, green, white backlight)
